# Raggy - A RAG chatbot

Provide him with docs, ask him on stuff about them, and he answers!

## Features

- CLI chat
- Protection against prompt injection
- Embedding by model `qwen3-embedding:0.6b`
- Chat capabilities powered by `llama3`

## Prerequisites

- Node.js v20+
- Ollama software
- AI Models: qwen3-embedding:0-06b and llama3

## Launch

```bash
npm install && npm start
```
